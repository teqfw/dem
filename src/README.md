# Logical runtime

`TeqFw_Dem_` maps to this `.mjs` namespace root. Compile is the supported logical
entry point. Registry and expression contracts are documented in the consumer
skill. Compile/A and Dto/Compile are internal pipeline components.

Api/Repository and Api/RepositoryProvider are portable host-substituted contracts.
Repository helpers and Selection validation are documented in the public
[access reference](../skills/teqfw-dem/references/repository.md).
