# @teqfw/dem

This skill matches package version 0.1.0. The package is a scaffold with no
functional DEM API. Host project instructions and accepted architecture govern
integration. Verify current installed package metadata and sources before
claiming any capability.

Preserve the logical/physical boundary and existing DEM v2 semantics during
future extraction. Do not invent tokens, supported declarations, migrations,
or compatibility promises. See [Scope and integration](references/scope.md).
