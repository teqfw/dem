# Changelog

## 0.1.0 — 2026-10-12

- Initialize a native ESM TeqFW package scaffold with the `TeqFw_Dem_` namespace.
- Add package installation/archive checks, JavaScript type checking, and CI.
- Distribute a version-matched `teqfw-dem` agent skill.
- Establish storage-independent positioning and preserve obsolete documents as legacy.
- Mount the independent private ADSM context outside Git and npm product contents.
- Change the license from GPL-3.0 to Apache-2.0 with explicit maintainer authorization.
- Standardize the public default branch as `main`, preserving existing history.

No functional DEM compiler or persistence API is implemented in this version.
